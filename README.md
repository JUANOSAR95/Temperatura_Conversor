# Conversor de Temperaturas

Aplicación web estática en HTML5, CSS3 y JavaScript vanilla.

## Ejecutar
Abre `index.html` directamente en un navegador.

## Desplegar
Sube los cuatro archivos al directorio raíz de GitHub Pages, Netlify o Vercel. No requiere compilación, backend ni variables de entorno.

## Archivos
- `index.html`: estructura accesible.
- `styles.css`: diseño responsive y animaciones.
- `script.js`: conversiones, validaciones e interacción.
